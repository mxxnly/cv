# Варіанти дизайну і логотипа MXXNLY Labs

Етап 2 ребрендингу. Ця папка повністю ізольована від коду сайту: статичні HTML, SVG і PNG,
жодних залежностей і зовнішніх запитів (шрифти системні, у продакшні будуть самохоститись).
Основний код у `backend/` і `frontend/` не змінювався. Результати розвідки (етап 1): `00-recon.md`.

## Як відкрити

1. `open design-proposals/index.html` (або двічі клацнути файл). Усе працює з диска.
2. Вгорі сторінки: блок «Живі макети поряд» показує три напрямки в iframe з одночасним
   перемиканням сторінки (головна / каталог / продукт), теми (світла / темна) і розміру
   (десктоп / мобільний). Нижче: логотипи, опис кожного напрямку, скриншоти, таблиця для Google Ads.
3. Кожен макет можна відкрити окремо: `designs/<напрямок>/{home,catalog,product}.html`.
   Параметр `?theme=dark|light` задає тему, кнопка в шапці перемикає її.
4. Логотипи: `logos/sheet.html` (усі файли поряд) і `logos/README.md` (пояснення ідей).

## Три напрямки логотипа

| | Ідея | Характер | Рідний дизайн |
|---|---|---|---|
| **01 Lattice** | два X ділять діагоналі, у перетині ромб-акцент; тонка монолінія | точний, редакційний | 01 Ledger |
| **02 Stitch** | округлі рядкові літери `mxxnly.labs`, два x зшиті в стібок, l з ніжкою | дружній, спокійний | 03 Soft |
| **03 Plate** | суцільна пластина з вибитими X і жовтою смужкою; жирний напис | майстерня, впевненість | 02 Workshop |

У всіх трьох дві літери X є головним графічним елементом; у 02 літера l має ніжку, у 01 і 03
напис великими літерами, тож L однозначна.

## Рекомендація

- **Дизайн: 01 Ledger** як основний варіант для реклами. Ціни й умови читаються як документ,
  реквізити продавця виглядають природно, сторінка найлегша. Для бухгалтерської аудиторії
  MXXNLY Invoice це найсильніший сигнал довіри; VPN при цьому не виглядає «підозріло яскраво».
- **Логотип: 03 Plate** або **01 Lattice**. Plate найкраще тримає малі розміри (favicon, іконка
  в оголошеннях, аватар у Telegram) і дає впізнаваність; Lattice делікатніший і органічний для
  Ledger. Якщо брати Ledger + Plate, пластину варто перефарбувати в чорнило/цеглу (три значення
  у `tools/make_logos.py`).
- Запасний варіант для максимально широкої аудиторії: **03 Soft** + **02 Stitch**; найдешевший
  за шрифтами, але найменш впізнаваний.
- **02 Workshop** найяскравіший і найбільш «свій», але жовтий акцент і жорсткі рамки гірше
  працюють для сторінок, де головне довіра до оплати; радше для сторінки «Про нас» або
  девелоперської документації.
