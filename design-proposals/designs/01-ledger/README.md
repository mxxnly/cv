# 01 · Ledger — «чесний прайс-лист»

**Ідея.** Сайт виглядає як акуратний друкований прайс-лист чи бухгалтерська книга: папір, чорнило, одна цегляно-червона
акцентна фарба. Замість «технологічних» карток із тінями — тонкі горизонтальні лінійки, нумеровані розділи («01 Продукти»),
ціни у вигляді відомості з табличними цифрами й крапковими лідерами. Це пасує продукту MXXNLY Invoice (накладні) і
загалом комунікує прозорість: ціни тут — головний контент, а не прикраса.

Логотип у макетах: `logos/01-lattice` (ґратка з двох X, ромб у центрі несе акцентний колір).

## Палітра

| Токен | Light | Dark |
|---|---|---|
| paper (фон) | `#F6F3EC` | `#141210` |
| surface (поля, банер) | `#FFFDF8` | `#1C1915` |
| ink (текст) | `#141210` | `#ECE7DC` |
| muted (другорядний текст) | `#6B655C` | `#A39C8F` |
| rule (лінійки) | `#D9D3C7` | `#2E2A25` |
| accent (цегляно-червоний) | `#C8381B` | `#E8603F` |
| on-accent | `#FFFFFF` | `#141210` |

Акцент використовується лише для: слова «від» біля ціни, курсивного слова в заголовку, активної лінійки при наведенні,
маркера «приклад», мітки «Тестові дані» та ромба в логотипі. Жодних градієнтів, тіней і розмиття.

## Типографіка

| Роль | Продакшн (self-hosted через fontsource) | Прев'ю в макетах (системний стек) |
|---|---|---|
| Заголовки | **Newsreader** (variable, opsz) | `"Iowan Old Style", "Charter", "Georgia", serif` |
| Текст, кнопки, форми | **Inter** (variable) | `-apple-system, "Helvetica Neue", Arial, sans-serif` |
| Мета, нумерація, мітки | системний `ui-monospace, Menlo` | те саме (не вантажимо окремий шрифт) |

Ціни — `font-variant-numeric: tabular-nums`, щоб цифри в таблицях вирівнювались. Базовий розмір тексту 17 px, рядок 1.55.

Очікуване шрифтове навантаження в продакшні: Newsreader variable latin+cyrillic ≈ 55–70 кБ (woff2, два файли:
roman + italic) + Inter variable latin+cyrillic ≈ 45–60 кБ. Разом ≈ 100–130 кБ, із `font-display: swap`.
Альтернатива «нуль кБ»: залишити системний стек із макетів; вигляд на macOS/iOS майже той самий, на Windows/Android — Georgia/Arial.

## Кнопки та картки

- **Кнопки:** прямокутні, радіус 2 px, висота 48 px (компактні — 44 px). Primary — заливка чорнилом, при наведенні стає
  акцентною. Secondary — контур 1 px. Без іконок-стрілок і «магнітних» ефектів.
- **Картки продуктів:** без заливки й рамок; рядки відомості з номером, назвою, описом, ціною «від» і статусом, розділені
  лінійками 1 px. При наведенні верхня лінійка «проводиться» акцентом. На десктопі — 4 колонки сітки, на мобільному — стек.
- **Тарифи:** три колонки, розділені вертикальними лінійками; великі табличні цифри; список «що входить» із тире.
- **Статуси:** монохромні мітки капітеллю з маленькою крапкою: Доступний (заповнена, акцент), Бета (контур), Скоро (пунктир).
- **FAQ:** нативні `<details>`, плюс/мінус у акценті.

## Google Ads: плюси й мінуси

**Плюси**
- *Читабельність:* великий серифний заголовок і спокійний текст 17 px; контраст тексту до фону ≥ 12:1 (light) і ≈ 13:1 (dark).
  Ціни видно одразу біля назви продукту — посадкова сторінка узгоджується з оголошенням.
- *Довіра:* стиль «відомості» прямо каже «ось ціни, ось продавець, ось умови». Блок продавця (ФОП), юридичні посилання,
  примітки про валюту/повернення/термін дії є на кожній сторінці та добре помітні, бо нічого їх не перекриває.
- *Швидкість:* один CSS ≈ 16 кБ, нуль JS (крім перемикача теми), жодних фонових картинок чи тіней із розмиттям,
  логотип — SVG на 1–2 кБ. Із системним шрифтом LCP залежить лише від HTML. Легко утримати Core Web Vitals у зеленій зоні.

**Мінуси**
- Для частини аудиторії «паперовий» стиль може виглядати консервативно й менше асоціюватись із софтом; VPN-продукту
  тут бракує «динаміки» — це компенсується ілюстраціями чи скриншотами продукту, яких у макеті немає.
- Серифний шрифт кирилицею на Windows без веб-шрифту відображатиметься Georgia — прийнятно, але менш характерно;
  якщо вантажити Newsreader, це +60–70 кБ.
- Мало кольору — у рекламних банерах і Open Graph-зображеннях доведеться спиратися на типографіку та червоний акцент.

## Файли

- `style.css` — усі токени, компоненти, обидві теми (`:root[data-theme="light|dark"]`).
- `home.html`, `catalog.html`, `product.html` — три екрани. Тема: `?theme=light|dark`, кнопка в шапці, інакше — система.
- Перевірено у headless Chrome на 1440 px і 390 px (через iframe, бо headless Chrome не дає вікно вужче за 500 px).
