# Напрямок 03 · «Soft» — спокійний продуктовий стиль

**Ідея.** Дружня, спокійна компанія-розробник продуктів. Замість рамок і тіней — пласкі тоновані
поверхні (шавлія, небо, пісок), великі радіуси, багато повітря, один глибокий бірюзовий акцент.
Кожен продукт має власний відтінок: MXXNLY VPN — «небо», MXXNLY Invoice — «шавлія», «Скоро» — «пісок».
Логотип у макетах: `logos/02-stitch` (округлий, нижній регістр, l з ніжкою).

Файли: `style.css` (усе спільне), `home.html`, `catalog.html`, `product.html` (MXXNLY Invoice).
Тема перемикається кнопкою в шапці або `?theme=light|dark`.

## Типографіка

- Продакшн: **Manrope** (уже самохоститься у проєкті через `@fontsource-variable/manrope`), один шрифт на все.
- Прев'ю в макетах (без зовнішніх запитів): `"Avenir Next", -apple-system, "Helvetica Neue", Arial, sans-serif`.
- Заголовки 700, трекінг −0.02em, H1 `clamp(2.1rem, 5.2vw, 3.6rem)`; текст 17px/1.55, дрібний службовий 13–15px.
- Еебров (надзаголовки) — 13px, верхній регістр, +0.1em, у кольорі primary.

## Кнопки і картки

- **Кнопки**: пігулки (radius 999px), висота 48px (44px у картках). Primary — заливка primary + білий текст;
  Secondary — тонована заливка (sage) + текст ink; третій рівень — текстове посилання зі стрілкою.
- **Картки**: radius 22px, пласка тонована заливка, без рамок, тіней і градієнтів. Ціна великою цифрою з
  чипом «приклад». Картка «Скоро» — пунктирна рамка без заливки.
- **Статуси**: пігулка на білій підкладці з крапкою: Доступний (зелений), Бета (синій), Скоро (пісочний).
- **Форми**: поля з тонкою рамкою `line`, фокус — обводка primary. Honeypot-поле приховане.

## Плюси й мінуси для Google Ads

**Плюси**
- Читабельність: один шрифт, великий кегль, високий контраст, короткі рядки — текст оголошення й посадкова
  сторінка читаються однаково легко на телефоні.
- Довіра: спокійна палітра без «технологічних» кліше, реквізити продавця, умови повернення й
  мітка «приклад» біля кожної ціни помітні, але не кричущі; виглядає як сервіс, а не як лендинг-одноденка.
- Швидкість: жодних зображень, тіней і фільтрів; увесь стиль — один CSS ~14 КБ; логотип SVG ~2 КБ.
  LCP — текстовий заголовок, CLS ≈ 0 (усі блоки мають фіксовані радіуси/відступи, без лейзі-контенту).

**Мінуси**
- Менш «впізнаваний»: подібна м'яка естетика поширена серед SaaS-сервісів, тож бренд тримається
  головно на логотипі й кольорах продуктів.
- Для VPN-оголошень тонована «небесна» картка може сприйматися як «легка» — варто посилити
  фактологію (шифрування, пристрої) у тексті.
- Темна тема менш контрастна у тонованих блоках; на деяких дисплеях картки зливаються з фоном
  (можна підняти яскравість `surface` на 1–2 кроки).

## Шрифтове навантаження в продакшні

- Manrope Variable (latin + cyrillic підмножини, woff2): ≈ 2 × 20–25 КБ ≈ **45–50 КБ**; інших шрифтів немає.
- Жодних іконкових шрифтів — іконки інлайн-SVG (по ~0.2 КБ).
