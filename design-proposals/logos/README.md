# Логотипи MXXNLY LABS: три напрямки

Усі файли згенеровано скриптом `../tools/make_logos.py`: літери побудовані з ліній на сітці,
тож SVG не залежать від шрифтів і однаково виглядають усюди. Перегляд поряд: `sheet.html`
(кнопка «Тема» перемикає світлий/темний фон).

У кожній папці:

| Файл | Призначення |
|---|---|
| `logo-on-light.svg` | повний лок-ап (знак + напис) для світлого фону |
| `logo-on-dark.svg` | те саме для темного фону |
| `mark-on-light.svg`, `mark-on-dark.svg` | знак окремо (аватар, соцмережі, app icon) |
| `favicon.svg` | favicon на світлій плитці, читається на 16 px |
| `favicon-dark.svg` | варіант на темній плитці (для `prefers-color-scheme: dark`) |

## 01 · Lattice (Ґратка)

Два X ділять внутрішні діагоналі; у перетині утворюється ромб, і саме він несе єдиний
колір (цегляний). Напис: тонкий монолінійний гротеск великими літерами, пара XX у слові
повторює знак, LABS меншим кеглем на тій самій базовій лінії.
Характер: точний, редакційний, «інженерний без неону». Найкраще пасує до дизайну 01 Ledger.
Ризик: на дуже малих розмірах тонкі лінії втрачаються, тому favicon має потовщені штрихи.

## 02 · Stitch (Стібок)

Округлі штрихи, рядкові літери `mxxnly.labs`. Два x торкаються в центрі й читаються як
безперервний стібок; крапка-акцент між словами. Літера l має ніжку (загнутий хвіст), тож
її не сплутати з I чи 1. Знак: xx у кільці з кольоровою крапкою.
Характер: дружній, спокійний, «продукт для людей». Пасує до дизайну 03 Soft.
Ризик: рядковий напис менш «корпоративний»; у документах варто дублювати назву текстом.

## 03 · Plate (Пластина)

Суцільна плитка з «вибитими» двома X і тонкою жовтою смужкою знизу (стрічка-маркер).
Напис жирним гротеском, слово LABS кольором акценту. Найкраще читається здалека і на
малих розмірах; favicon фактично і є знаком.
Характер: майстерня, інструменти, впевненість. Пасує до дизайну 02 Workshop.
Ризик: найважчий візуально; потребує повітря навколо, у довгому тексті може «кричати».

## Як регенерувати

```bash
python3 design-proposals/tools/make_logos.py
```

Кольори кожного напрямку задані в словнику `DIRECTIONS` у скрипті (чорнило/папір/акцент
для світлого й темного варіантів); логотип з одного напрямку можна перефарбувати під
палітру дизайну з іншого, змінивши три значення.
